# 一、问题与假设

考虑无限长的一维均匀介质。扩散系数 D 为正常数，无对流、反应或边界影响。初始物质量 M 集中在原点，观察量为浓度 u。

研究目标是比较不同位置达到同一相对浓度比例的时间，并讨论如何利用距离与时间估算 D。

# 二、扩散解析解

一维扩散方程为 u_t = D u_xx。点源初始条件对应高斯基本解：

![一维扩散方程的点源解析解](/papers/figures/heat-kernel.svg)

其中 t 大于零，M 为总物质量。这个解析解是经典热方程基本解，并非本文提出的新方法。

# 三、定义相对阈值

令 R(x,t) = u(x,t) / u(0,t)。利用同一时刻的中心浓度归一化，可消去 M 和随时间变化的前因子，得到 R = exp[-x²/(4Dt)]。

给定零到一之间的阈值 r，令 R(x,t) = r。对非零距离求解时间：

![相对阈值时间和时间比值](/papers/figures/time-ratio.svg)

因此，在相同 r 下，两点时间比等于距离平方比。距离翻倍，达到相同比例的时间变为四倍。

# 四、参数估算

仅有时间比值时，D 已被消去，不能单独识别扩散系数。必须再给出至少一个绝对时间、位置距离及所使用的阈值。

由解析式可得 D = x² / [4t ln(1/r)]。可对多个位置分别计算 D，再检查估算值是否一致。

# 五、可复算的例子

设 D = 0.5 cm²/s，取 r = exp(-1)。位置 x1 = 2 cm 对应 t1 = 2 s；位置 x2 = 4 cm 对应 t2 = 8 s。

此时 t2/t1 = 4，与距离平方比相同。把 x1 和 t1 代入估算式，可恢复 D = 0.5 cm²/s。这只是代数一致性检查，不构成实验验证。

![理论演算中的距离与时间示意](/papers/figures/example.svg)

# 六、误差与适用边界

当阈值 r 接近一时，ln(1/r) 很小，时间估计对测量误差更敏感。距离误差也会通过平方关系放大。

固定绝对浓度阈值不等同于固定相对阈值。绝对浓度中仍有 t 的平方根因子，不能直接使用上述距离平方比结论。

有限边界、非均匀介质、源的有限宽度、反应及对流，都可能改变解析式。真实数据接入后，应先检查这些假设，不能仅凭比值吻合认定模型正确。

# 七、结论

在无限一维点源扩散模型和固定相对阈值下，特征时间与距离平方成正比。时间比值适合检查扩散尺度关系；估算 D 还需要绝对时间与距离信息。
