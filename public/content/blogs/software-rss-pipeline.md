# RSS 数据管道：从外部 XML 到可读的知识世界

这是一篇 AI 辅助整理的技术学习草稿，供作者审阅后补充真实实践。它不代表作者已经完成相关项目、实验或论文复现。

## 要解决的问题
RSS 发布与 RSS 聚合是两个方向。本站 feed.xml 描述已发布博客；外部订阅先经过 HTTPS 下载、体积限制、XML 解析和统一字段映射，再成为本站静态 JSON。浏览器不直接抓取第三方 Feed，避免 CORS 和运行时不稳定。

## 一个可操作的思考示例
一次抓取保存 sourceId、稳定条目 ID、标题、原文链接、摘要、发布日期与抓取时间。RSS 2.0 与 Atom 的字段不同，由适配器处理。OPML 只描述订阅清单，不复制文章全文。缺少日期就标为未提供，不填当前时间冒充发布。

## 容易忽略的边界
Feed 不是可信程序。必须拒绝 DTD 与危险 URL，只显示文本；重定向也要检查来源范围。失败不能清空旧文章，ONLINE 只能代表上次抓取成功，不能代表实时可用。

## 如何确认理解与实现
验证转义、格式、去重、日期排序和失效缓存；打开 /feed.xml 与 OPML 检查结构；确认草稿没有进入本站订阅源。
