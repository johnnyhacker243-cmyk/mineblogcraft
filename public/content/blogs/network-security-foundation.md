# 从 TCP/IP 开始理解网络安全

这是一篇 AI 辅助整理的技术学习草稿，供作者审阅后补充真实实践。它不代表作者已经完成相关项目、实验或论文复现。

## 要解决的问题
网络安全分析需要先知道通信发生在哪一层。IP 负责地址与转发，TCP 维护连接与可靠传输，应用协议定义业务语义。端口能提示服务入口，却不能单独证明具体应用、版本或漏洞存在。

## 一个可操作的思考示例
在自己的本地环境观察一次浏览器请求：名称解析、连接建立、TLS 与 HTTP 各自承担什么责任。把时间线画出来，再区分连接失败、证书错误和 HTTP 错误；三者需要不同的排查证据。

## 容易忽略的边界
看到开放端口就下漏洞结论，会跳过服务确认和影响分析。扫描结果还可能受到代理、负载均衡或防火墙影响。实验只应发生在自己或明确获授权的环境。

## 如何确认理解与实现
能解释地址、端口、协议与应用的关系；能把一次失败定位到具体层次，并写清观察与推断的区别。
