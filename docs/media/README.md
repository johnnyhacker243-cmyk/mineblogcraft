# README 展示资源

本目录仅保存项目首页文档使用的 Logo 与实际页面截图。由项目所有者明确指定用于 README 展示并提交 GitHub，素材权利范围见根目录 `ASSET_LICENSES.md`。

- 采集日期：2026-10-17（Asia/Shanghai）。
- 浏览器：Playwright 驱动 Chromium，常规截图 1600 × 1000，Wiki 两张截图为 1600 × 1200，设备像素比 1。
- 画面来源：当前源码的本地生产构建；`blog-subscription.jpg` 另从现有公网网站拍摄，以展示实际公网订阅地址。
- 图像处理：页面截图直接以 JPEG 输出，没有拼接或改写页面内容；Logo 保留用户提供的 PNG 原始字节。
- 采集范围：主菜单、作者介绍、博客列表/正文/订阅、RSS、论文书架/原文、Wiki 图谱/详情、构建报告及 MineWorld。
- 页面计数和构建标识对应拍摄时的内容与版本，后续变更应同步更新相应展示图。

游戏图形、第三方论文和上游客户端在截图中的呈现不改变其各自权利归属。测试截图、源素材、音频与个人缓存继续使用原来的忽略规则，不在本目录归档。
