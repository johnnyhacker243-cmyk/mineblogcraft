# MineResearch 近期论文目录（2026-10-16）

替换可见书架中的早期经典条目与虚构示例，保留原书架、打开动画、双页 PDF 和放大阅读功能。旧内容文件未删除，历史目录可从 Git 恢复；不将旧链接偷换成不相关的新论文。

- AI、网络安全、软件工程各 11 篇，共 33 篇真实外部研究。
- 首次公开年份从 2024 年起，近期研究优先，兼顾 GraphRAG、Mamba-2、OLMo 2、SWE-agent、Agentless、SWE-Bench Pro、CYBERSECEVAL 3 等原始论文。
- 近期主题包括 MoE 路由、持续学习、检索与知识组织、MCP 权限边界、隐私核算、Rust 静态分析、依赖治理、代码审查、长程工程评测与交付。
- 32 篇 arXiv 记录使用精确版本、完整作者名单和首次公开日期，统一标注“预印本”，不根据投稿或索引信息声称经过同行评审。保留 NIDS-FGPA 2024 年已发表原文。
- 中文简介为根据原摘要撰写的主题导读，不是原论文译文或个人实验结果；不将论文报告的指标作为本站验证结果。

## 数据与来源

`config/researchSelection.json` 保存 32 篇 PDF 论文的 arXiv 版本、作者、首次公开/更新日期、原摘要、许可、中文导读、标签及概念关联。元数据来自 arXiv Atom API，许可来自对应版本的摘要页，不根据标题猜测正文。

`scripts/apply-research-selection.mjs` 组合该配置与已有 NIDS-FGPA 结构化原文，生成 `src/data/papers.json`，按新到旧排列，并更新 `wiki.json` 的相关论文。34 个 Wiki 概念的位置、连线、内容和 UI 不变。无合适新文献的经典数学节点允许为空，不用语言模型论文冒充扩散方程建模文献。

## 全文与许可

`config/paperFulltextSources.json` 指向精确版本的规范 PDF；`npm run papers:verify` 下载、解析、匹配首页标题，检查实际末页，记录完整文件页数、大小、SHA-256 和审计日期到 `public/papers/fulltext-catalog.json`。文件完整性核验不等同于逐页学术审稿。

本批 32 份 PDF 均为 CC BY 4.0 或 CC BY-SA 4.0。`scripts/prepare-hosted-papers.mjs` 仅允许这两种明确许可和受限文件路径，生成逐字节不变的同域全文及 `ATTRIBUTION.json`，保留原作者、原链接、许可链接。BY-SA 论文仍按原许可提供；未改写 PDF，不追加封面或删减图表。

原 PDF 被 Git 忽略，构建从已发布同域副本或规范源恢复，必须匹配审计哈希/大小。不会把 HTML 错误页当 PDF、引入跨域代理或允许任意地址。首次本地核验后的临时审计文件可离线复用。恢复失败会停止构建，不发布缺全文的书架。

首页不请求 PDF；点击书籍后按需下载一篇，仅渲染当前双页。图表、公式和附录来自原 PDF，保持现有双页纸张融合与点击放大能力。

## 后续更新

1. 核实作者、精确版本、首次公开时间、完整 PDF 和许可。
2. 更新选题配置与全文来源登记；非开放许可原文不可套用自托管策略。
3. 执行 `node scripts/apply-research-selection.mjs`、`npm run papers:verify`、`node scripts/prepare-hosted-papers.mjs`。
4. 执行内容测试、构建和浏览器阅读验收；首次发布新的许可全文后再触发自动构建，避免发布环境缺少首次恢复来源。

不自动用新版本覆盖已审计 PDF，避免页数、引用和哈希漂移。未来 API 可返回同样的论文结构，无需改造书本 UI。
